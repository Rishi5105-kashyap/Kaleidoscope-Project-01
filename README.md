# Kaleidoscope Project 01 🎨

My first fun project using Antigravity. Hope you like it :-)

## Overview

This project explores creative visual effects using web technologies. It combines **JavaScript**, **CSS**, and **HTML** to create an interactive and visually stunning kaleidoscope experience.

## Technology Stack

- **JavaScript** (67.3%) - Core logic and interactivity
- **CSS** (19.5%) - Styling and visual effects
- **HTML** (13.2%) - Structure and markup

## Features

- Interactive kaleidoscope visualization
- Antigravity-powered animations
- Responsive design
- Smooth visual effects

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Explore and interact with the kaleidoscope

## Installation

No installation required! Simply clone and open the HTML file in your favorite browser.

```bash
git clone https://github.com/Rishi5105-kashyap/Kaleidoscope-Project-01.git
cd Kaleidoscope-Project-01
```

## Browser Compatibility

This project works best in modern browsers that support:
- ES6+ JavaScript
- CSS3 animations and transforms
- HTML5
